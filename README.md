# FoodApp_WebApp
Modern ételrendelő app, amely összeköti a felhasználókat a helyi éttermekkel és futárokkal. Gyors rendelés, egyszerű fizetés.

## Running the app

Run `npm run dev` from the repository root to start the backend and Expo's mobile development server. Scan the QR code in the terminal with Expo Go to open the mobile app.

To start only the mobile development server, run `npm run start:mobile`. To start the app in a web browser, run `npm run start:web`.
